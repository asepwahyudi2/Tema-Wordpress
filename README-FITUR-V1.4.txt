Game Repack Theme v1.4 - Pro Feature Update

Fitur baru:
1. Report Broken Link
   - Tombol otomatis tampil di single game/software.
   - Mengarah ke halaman /request/ dan prefill judul postingan.

2. Changelog / Update Box
   - Isi melalui meta box: Changelog Version, Date, Status, Notes.

3. Disclaimer Box
   - Otomatis tampil di halaman detail game/software.

4. Official Link Button
   - Isi melalui meta box Official Link 1-3.
   - Untuk software, Official Website juga otomatis ikut tampil.

5. Rating Review
   - Isi rating 0-10 di meta box.
   - Tampilan rating bar otomatis muncul jika diisi.

6. Badge Status
   - Isi "Updated, Popular, Recommended" di field Badge Status.
   - Tampil di header detail dan card postingan.

7. Request Form
   - Halaman /request/ memakai shortcode [game_repack_request_form].
   - Form dikirim ke email admin WordPress lewat wp_mail().

8. Tutorial Section
   - Homepage punya section Latest Tutorials.
   - Buat post biasa dan masukkan kategori Tutorial.

9. Schema SEO
   - JSON-LD otomatis untuk Game, Software, dan Article.
   - Game memakai VideoGame, Software memakai SoftwareApplication.

10. Speed Optimization
   - Custom JS diberi defer.
   - Image diberi lazy loading + async decoding.
   - Preconnect untuk Google Fonts dan CDN Font Awesome.

Setelah install/update:
- Buka Settings > Permalinks > Save Changes.
- Pastikan halaman Request dan Tutorial sudah ada.
- Untuk tutorial, buat posting biasa lalu pilih kategori Tutorial.
