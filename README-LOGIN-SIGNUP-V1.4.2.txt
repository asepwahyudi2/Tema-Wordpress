Game Repack Theme v1.4.2 - Login & Signup Update

Fitur baru:
- Tombol Login dan Signup otomatis tampil di header.
- Halaman /login/ otomatis berisi shortcode [game_repack_login_form].
- Halaman /signup/ otomatis berisi shortcode [game_repack_signup_form].
- Front-end login dan signup tanpa plugin tambahan.
- Role user baru otomatis Subscriber.
- Pendaftaran user WordPress otomatis diaktifkan saat update/aktivasi tema.
- User login akan melihat tombol profile dan logout di header.

Setelah upload/replace tema:
1. Buka Settings > Permalinks > Save Changes.
2. Cek halaman: /login/ dan /signup/.
3. Cek Settings > General:
   - Membership: Anyone can register
   - New User Default Role: Subscriber
4. Jika pakai plugin cache, clear cache.
